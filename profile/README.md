## 👋 Quiénes somos

**Organizer SpA** es una empresa chilena de software. Desarrollamos **Organizer**, una plataforma SaaS para que pymes y emprendedores ordenen su operación diaria, y además construimos **software a medida** para nuestros clientes.

## ✨ Qué ofrece Organizer

- 📦 **Inventario avanzado**: control de stock, productos y movimientos
- 🧾 **Ventas y facturación electrónica**
- 👥 **Clientes y proveedores** centralizados
- ✉️ **Notificaciones por correo**
- 🔐 **Inicio de sesión con Google**

> 🎁 **Prueba Organizer gratis por 90 días** en [app.organizer.cl](https://app.organizer.cl)

## 🛠️ Servicios

- Desarrollo de software a medida (web, móvil y backend)
- Consultoría informática y arquitectura de software
- Procesamiento de datos y hospedaje
